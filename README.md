# Sakila SQL Analysis

SQL analysis project based on the Sakila SQLite database.

## Project Overview

This project uses SQL queries to analyze the Sakila database and extract KPIs, business insights and analytical outputs.

The workflow is:

1. Download the Sakila SQLite database using Python
2. Run SQL queries on the database
3. Export query results as CSV files
4. Use the extracted data to build a final KPI and insight presentation

## Tools Used

- SQL
- SQLite
- Python
- pandas
- GitHub
